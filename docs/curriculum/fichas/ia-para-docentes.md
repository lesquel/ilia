# Ficha — IA para preparar tu próxima clase

Curso: `introduccion-ia-docentes`. Formación docente introductoria; la ruta usa ejemplos de aula y no asigna una destreza estudiantil propia al curso.

| Campo | Anclado |
|---|---|
| Destinatario | Docentes que empiezan a probar IA generativa para preparar una clase |
| Grado de ejemplo | 7.º EGB en lectura; se aclara que es un ejemplo, no el alcance de todo el curso |
| Destreza del curso | No aplica: formación docente; no se asigna una destreza estudiantil |
| Indicador | No aplica a la ruta de formación docente |
| Logro Ineval | No se usa ni se promete una cifra |
| Artefacto final | Un pedido revisable para una actividad de la próxima clase del docente |
| Cuidados | Revisar el material, trabajar desde fuentes aportadas y evitar nombres, calificaciones, diagnósticos y datos identificables |
| Estructura | Cuatro módulos; video breve, dos lecturas, una comprobación de cuatro preguntas y un examen final de producción |

El ejemplo lector de séptimo se limita al párrafo sobre el huerto, cinco preguntas respondibles desde el texto y una clave al final. No se atribuye una destreza o estadística a todo el curso.
