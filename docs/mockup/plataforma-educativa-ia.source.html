Sobre este curso

Un recorrido práctico por los modelos de difusión y las técnicas de prompting que se usan hoy en producción. Cada módulo termina con una actividad ejecutable, y el curso cierra con una evaluación demostrativa en el laboratorio: generas una imagen a partir de un enunciado y el sistema puntúa cumplimiento, calidad del prompt, coherencia y composición.

Qué vas a poder hacer

— Estructurar un prompt en sujeto, estilo, luz y composición
— Controlar la coherencia entre varias generaciones
— Elegir el modelo adecuado para cada encargo
— Iterar sobre un resultado con variaciones dirigidas
— Documentar y versionar tus prompts
— Evaluar críticamente una imagen generada

¿Cuál es la diferencia entre un prompt descriptivo y uno estructurado?

{{ vereditoTexto }}

El prompt descriptivo enumera lo que se quiere ver en lenguaje corriente. El estructurado separa las decisiones en campos — sujeto, estilo, luz, composición, contexto — de modo que cada una puede ajustarse sin reescribir el resto y el resultado es reproducible entre generaciones.
