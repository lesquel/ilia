# ILIA

Cuando diseñes o reescribas un curso, lección, folio, guion o lámina, lee `.cursor/skills/diseno-curso-ilia/SKILL.md` y `.cursor/skills/voz-profesor-ilia/SKILL.md` antes de escribir. La mesa es `docs/curriculum/`. No inventes un código de destreza ni una cifra Ineval.

La voz es de un docente que forma docentes: sala de profesores, no rúbrica. Lía no habla en la lección.
